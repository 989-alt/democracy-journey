# Product

<!-- impeccable:product-schema 1 -->

하네스 규칙에 따라 `docs/democracy-journey/` 에 둔다. 사실은 `PRD.md`(사용자 승인 2026-10-10, 브레인스토밍 결정 포함)와 `교과분석.md` 에서만 옮겼다. 인터뷰 대신 PRD 승인 이력이 출처다. 시각 세계는 여기 없다 — `DESIGN.md`.

## Platform

web

## Stack

delegated: Vite 6 + TypeScript 5 + Preact 10, `vite-plugin-singlefile` 단일 HTML(에셋 base64 인라인, 8MB 이하), CSS 커스텀 프로퍼티 시멘틱 토큰 + `--sat-step`. Phaser 없음 — 서사·카드·드래그는 전부 DOM(PRD §11). 백엔드·네트워크 호출 0, localStorage 저장.

## Users

초등학교 6학년 1학기 **말** 학생(만 11~12세). 사회 1단원 ② 「민주화와 산업화」, 2단원 「민주주의와 시민 참여」를 모두 배운 뒤 단원 마무리·복습 차시 1회(40분) 안에서 태블릿(가로 1024×768)으로 **혼자** 30~38분 플레이. 교사 개입 없음, 교사 화면 없음. 장 끝마다 자동 저장, 이어하기 가능.

## Product Purpose

성취기준 [6사08-01][6사08-02][6사08-03][6사07-02] 의 지도 내용 1~72(범위 밖 16·47)를 **1950년생 한 사람의 1960~오늘 삶**으로 다시 만나게 한다. 역사는 교과서 그대로 일어나고, 바뀌는 것은 내 형편(참여·정보·살림 3칸)과 관계다. 장마다 한 번 그 시대 보통 사람이 해야 했던 판단을 학생이 한다(판별 5종). 성공은 PRD §7 판정식 S1~S10 으로 잰다(5장 완주, 판별 5종 정답률, 비교 카드 5장 열람, 오개념 M14·M11·M25 선택 0).

## Positioning

역사 퀴즈가 아니라 **"무엇이 잘못됐는지 가려내는" 회고록**이다. 플레이어의 환상: "나는 역사를 바꾸지 못한다. 하지만 무엇이 잘못됐는지는 내가 가려낼 수 있다." 선택은 사건을 바꾸지 않고 대사·형편만 바꾼다. 세피아에서 시작해 장이 갈수록 색이 번지고(`--sat-step` 0→4), 2단원의 오늘날 제도는 장마다 풀컬러 "그때와 오늘" 비교 카드 1장으로만 들어온다.

## Operating Context

- 교실 전자칠판 또는 개인 태블릿 가로. 마우스·터치·키보드(숫자키 1~3, Enter). 히트박스 44px 이상, 드래그는 탭-탭 대안 병행.
- 저장: `localStorage` 키 1개(`dj.save.v1`), 장 끝마다 덮어쓰기. 학생 입력 0.
- 배포: 정적 HTML 1개, `file://` 로도 열림. 외부 요청 0, 폰트 self-host.
- 소리: BGM 5곡(Lyria), 효과음 5종(Lyria 또는 CC0 — 02 열린 질문). 음성 없음.

## Capabilities and Constraints

- 5장(1960 봄 / 1961~1979 긴 집권의 시대 / 1980 5월 / 1987 6월·12월 / 에필로그 오늘) + 결과 화면(인생 연표). 장면 30개 안팎, 장면당 선택지 2~3(잠김 최대 1, 조건은 한 수치 `min` 하나).
- 판별 5종: ① 투표소 핫스팟 6, ② 호소처 카드 4+까닭 3지, ③ 정보 카드 4×기준 4+신뢰도 3단계, ④ 공약 채점표 3×3→투표, ⑤ 기관 카드 8+견제 3. 타이머 없음, 오답도 진행, 틀린 판단은 다음 장 "다시 보기"에서 최대 2회.
- 수치로 정답을 사는 길도, 정답 없이 수치로 이기는 길도 없다(PRD §4.3).
- 용어·묘사 상한은 **교과서 본문**: '유신'은 라벨에 쓰지 않고 2장 어른 대사 1줄에만. 3장은 "폭력적으로 진압", "많은 시민이 희생", "방송은 폭도라고 했다"까지. 총·시신·고문 장면·소리 없음. 실제 인물 얼굴·국기·브랜드·그림 속 글자 없음.
- 개인정보: 학생 입력 0, 계정·랭킹 없음.
- 미정: Q2 M21(선거하면 곧 민주주의) 추론 채택, Q3 교과서 출판사명(결과 화면 출처는 "사회 6-1 교과서"), Q5 5·18 묘사 수위(§4.9 상한, 02 시안에서 재확인), 효과음 출처.

## Brand Commitments

- 제목 「민주주의의 여정」. 원안은 아티팩트 「5종 게임 제작 정리서 v1.1」 08 절, 다른 결정은 PRD §13.
- 모든 이미지 요소(장면·초상·비교 카드·판별 자료·UI 패널·버튼·아이콘)는 GPT-6.1-sol 생성 PNG. SVG·CSS 로 그린 평면 UI 금지, 그림체는 이 게임 고유(world-trade 복제 금지) — 사용자 규칙 2026-10-10.
- 색 번짐 장치: 1장 세피아 근처 → 에필로그 풀컬러. 비교 카드·UI 크롬은 항상 풀컬러.

## Evidence on Hand

## Product Principles

- 교과서 문장이 먼저. 재미 장치는 그 문장을 한 사람의 삶 안에서 다시 읽게 하는 데만 쓴다.
- 판별은 "출처 종류"가 아니라 "기준"으로 판단하게 한다(M14·M18). 결과 화면은 선택을 평가하지 않고 판별 정답률·연표만 보인다.
- 한 화면에 결정 하나. 안내문·힌트·부제 없음(world-trade 에서 확정된 사용자 규칙).

## Accessibility & Inclusion

본문(대사) 20px 이상, 제목 24~30px, 손글씨 서체는 메모·회상 컷에만. 수치·신뢰도·판정은 색만으로 나누지 않는다(아이콘·글자 동반). 키보드로 전 장면 진행, 포커스 링 3px. `prefers-reduced-motion` 에서 유도 화살표·색 번짐 전환 정지. 효과음은 전부 시각 피드백 동반.
