## 2. 게임 한 줄

1950년에 태어난 한 사람이 1960년 봄부터 오늘까지를 산다. 역사는 교과서 그대로 일어나고, 바뀌는 것은 내 형편과 관계다. 장마다 한 번, 그 시대 보통 사람이 해야 했던 판단을 내가 한다.

플레이어의 환상: "나는 역사를 바꾸지 못한다. 하지만 무엇이 잘못됐는지는 내가 가려낼 수 있다."

### 4.2 장면 데이터

```ts
type Scene = { id; chapter; bg; portrait:'y10'|'y20'|'y30'|'y37'|'old'; text:string[];   // 대사 2~3문장
  options: { label; delta:{join?;info?;home?}; lock?:{stat;min}; flag?:string; next?:SceneId }[];  // 2~3개
  kind:'story'|'culture'|'judge'|'compare'|'retry'|'title' }
```
- 선택지는 역사를 바꾸지 않는다. `next` 는 장면 분기(대사 변주)만, 사건 순서는 고정.
- "모든 선택이 다음 장에서 한 번 이상 언급" — 각 장의 첫 장면 대사에 직전 장 플래그 변주 1문장.
- 잠금: 장면당 최대 1개, 조건은 한 수치 `min` 하나. 흐리게 + 부족 아이콘.

### 4.3 수치 3개 (참여·정보·살림)

아이콘 + 3칸 게이지, 숫자 없음. 선택지마다 ±1(0~3 클램프). 판별 정답·오답은 수치를 건드리지 않는다. 판별 정답은 `flag:'knows_<kind>'` 만 켜고 다음 장 대사를 "아는 사람" 변주로 바꾼다. 수치로 정답을 사는 길도, 정답 없이 수치로 이기는 길도 없다.

### 4.4 판별 5종

### 4.5 비교 카드 "그때와 오늘"

판별 직후 1장면. 풀컬러(색 번짐의 예외 — 카드만 오늘의 색). 왼쪽 "그때" 삽화 + 한 줄, 오른쪽 "오늘" 삽화 + 2단원 사실 2~3줄. 탭 1회로 넘김, 문항 아님, `compare_view` 로그만. 2단원 사실 항목(19~24, 42~46, 30~36)의 **유일한 자리**다.

### 4.6 생활 문화 사례 (장마다 1장면)

사례 1개를 장면으로 보여 주고 "왜 이렇게 달라졌나" 3지 선택(정답 1 = 교과서 까닭). 예: 2장 경부 고속 국도 → "서울~부산 하루 걸리던 길이 4시간 반" → 까닭 "수출품을 빨리 나르려고 발전소·고속 국도·항만을 지었다"(62). 과정 중심 평가 4 "변화가 나타난 까닭"에 대응.

### 4.7 색 번짐

`--sat-step` 0(1장, 흑백 근처) → 1 → 2 → 3 → 4(에필로그 풀컬러). 장 끝 전환 1.5초. 비교 카드는 항상 4.

### 4.8 조작

마우스·터치·키보드. 카드 탭 또는 숫자키 1~3. 판별⑤ 드래그는 Pointer Events, 드래그 영역 `touch-action:none`, 탭-탭 대안 병행. 최소 히트박스 44px. 3초 무입력 시 첫 카드에 화살표. 첫 30초 안에 카드 1장 선택, 3분 안에(1장 판별 전) 모든 조작 노출.

### 4.9 묘사 상한

교과서 본문이 상한. 3장: "폭력적으로 진압", "많은 시민이 희생", "방송은 폭도라고 했다", 꼬마 상주는 **언급만**. 총·시신·고문 장면·소리 없음. 박종철은 "경찰의 고문으로 사망" 한 줄. 지도서 참고 자료(시신 유기·최루탄 피격 상세·서동요 등)는 쓰지 않는다.

## 7. 성공 판정식 (실행 가능)

한 판 로그(`Save.log`)에 대해 아래가 전부 참이면 "완주 통과". Vitest 가 이 판정 함수를 검사하고, Playwright e2e 가 시드 고정 완주에서 같은 함수를 호출한다.

| # | 판정식 |
| --- | --- |
| S1 | `chapter_end` 1~5 각 1개 이상 |
| S2 | `judge` kind 5종 각각 1개 이상 |
| S3 | `judge poll correct && item∈violations` 개수 ≥ 3 (4개 중), `item∈traps && !correct` 가 attempt 최종에서 0 |
| S4 | `judge appeal correct` 최종 attempt 참 |
| S5 | `judge source` 카드 4장 중 ≥ 3 장 신뢰도 정답(최종 attempt) |
| S6 | `judge pledge` 최종 선택 = 총점 최고 후보 AND 채점표 9칸 채움 로그 선행 |
| S7 | `judge organ` 견제 방향 3개 중 ≥ 2 정답, 분류 8개 중 ≥ 6 |
| S8 | `compare_view` 1~5 전부 |
| S9 | `culture` 5개 중 ≥ 4 `correct` |
| S10 | 오개념 0회: 최종 attempt 에서 M14("방송이니까 사실") 선택 0, M11("권력이 세면 안전") 선택 0, M25(회상 장면 "5·18 결과") 선택 0 |

"재미있음"은 판정식이 아니다. 플레이 시간은 e2e 에서 30~38분 상한을 **장면 수 × 평균 체류 추정**으로만 체크(클릭 수 ≤ 120).

## 9. 데이터 모델 초안

저장소: `localStorage` 키 `dj.save.v1`. 자동 저장은 로그가 추가될 때마다(장 시작 토스트는 표시만). 완주 저장본은 결과 화면으로 복원, "다시하기"에서 삭제. 학생 입력 0개, 개인정보 없음(권한 레벨 6 해당 없음). 서버 없음.

```ts
type Save = { version:1; seed:number; chapter:1|2|3|4|5; sceneIdx:number;
  stats:{join:0|1|2|3; info:0|1|2|3; home:0|1|2|3}; flags:string[];
  log:LogEvent[]; retryQueue:JudgeItemId[]; stage:'title'|'play'|'done' };
type LogEvent =
 | {t:number; type:'choice'; scene:SceneId; option:string; delta:Partial<Stats>}
 | {t:number; type:'judge'; kind:'poll'|'appeal'|'source'|'pledge'|'organ'; item:JudgeItemId; answer:string; correct:boolean; attempt:1|2|3}
 | {t:number; type:'compare_view'; chapter:1|2|3|4|5}
 | {t:number; type:'culture'; chapter:1|2|3|4|5; example:string; reason:string; correct:boolean}
 | {t:number; type:'chapter_end'; chapter:1|2|3|4|5}
 | {t:number; type:'screen'; name:string};
```

CONTENT 블록(`src/content/*.ts`, 빌드 후 파일 상단 한 객체): `scenes[]`, `judges{poll,appeal,source,pledge,organ}`, `compares[5]`, `cultures[5]`, `timeline[]`(고정 사건 연표), `copy{}`(라벨·피드백 문구). 문항·대사·라벨은 여기에만 있다.
